# Zepp Step Manager

一个简单的小米运动（Zepp Life）步数提交工具，Python 运行，不需要搭建服务器。

## 能做什么

- 使用 Zepp Life 手机号或邮箱登录
- 自动读取账号已经绑定的手环或手表
- 提交指定步数
- 获取支付宝授权入口
- 查询支付宝绑定状态

微信绑定目前没有经过验证的 Zepp 授权流程，所以暂时没有实现。等接口和流程确认后再添加，不放一个不能用的空功能。

## 安装

需要 Python 3.10 或更新版本。

```bash
pip install -r requirements.txt
```

## 提交步数

运行：

```bash
python zepp.py
```

按提示输入小米运动账号、密码和步数即可。密码输入时不会显示在屏幕上。程序会从当前账号读取已绑定设备，不需要自己填写设备 ID。

## 绑定支付宝

运行：

```bash
python alipay.py
```

程序会先查询当前绑定状态，再生成支付宝授权入口。请在手机上打开授权入口完成操作，之后重新运行程序查询绑定状态。

## 文件说明

- `zepp.py`：登录小米运动、读取设备、提交步数。
- `alipay.py`：获取支付宝授权入口、查询绑定状态。
- `requirements.txt`：运行需要的 Python 依赖。

## 说明

这是基于现有接口行为整理的个人学习项目。相关接口可能随 Zepp Life 版本变化而失效，使用前请自行确认平台规则。请勿把账号密码、Token 或个人设备信息提交到公开仓库。
