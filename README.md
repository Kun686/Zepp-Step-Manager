# Zepp Step Manager

一个简单的小米运动（Zepp Life）步数提交工具，使用 Python 运行。

目前包含：
- Zepp Life 账号登录
- 查询账号下已绑定的手环或手表
- 提交指定步数
- 获取支付宝授权入口
- 查询支付宝绑定状态

微信绑定目前没有可验证的 Zepp 授权流程，所以暂时没有实现，不会用空函数假装支持。

## 安装

需要 Python 3.10 或更高版本。

    pip install -r requirements.txt

## 提交步数

    python zepp.py

按提示输入 Zepp Life 账号、密码和要提交的步数。程序会查询账号下已绑定的设备，再提交数据。

## 支付宝绑定

    python alipay.py

程序会查询当前绑定状态并生成授权入口。请在手机上使用支付宝打开授权入口，完成后重新运行查询状态。

## 注意

- 账号密码只在运行时输入，不会写入配置文件。
- 项目不会内置个人账号、设备 ID 或 Token。
- 步数模板从上游公开项目读取；如果上游格式变化，提交功能可能需要调整。
- 这是个人学习和研究用途。请遵守 Zepp Life、支付宝及相关平台的服务条款。

## 文件说明

- zepp.py：登录、设备查询和步数提交。
- alipay.py：支付宝绑定状态和授权入口。
