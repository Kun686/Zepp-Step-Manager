# Zepp Step Manager

一个简单的 Zepp Life（原小米运动）网页工具。运行后打开浏览器，注册或登录自己的 Zepp Life 邮箱账号，就能选择设备、提交步数，以及绑定微信和支付宝。

## 功能

- Zepp Life 邮箱注册（需要图片验证码）
- Zepp Life 邮箱登录
- 自动读取账号已经绑定的手环或手表
- 选择设备并提交步数
- 查询微信运动绑定状态、生成微信绑定二维码
- 查询支付宝绑定状态、获取支付宝授权入口
- 登录凭据加密保存在本机

## 运行

需要 Python 3.10 或更新版本。

```bash
pip install -r requirements.txt
python app.py
```

浏览器打开：

```
http://127.0.0.1:8010
```

注册时先获取图片验证码，按提示完成注册；已有账号选择登录。登录后选择设备、填写步数并提交。微信和支付宝绑定入口都在同一个页面。

## 数据保存

首次运行会创建 `instance/` 目录，里面有本地数据库和加密密钥。账号认证信息使用 Fernet 加密保存在本机。请备份整个 `instance/` 目录；如果丢失 `credential.key`，原来的加密数据将无法解密。

默认只监听本机 `127.0.0.1`。不要直接把服务暴露到公网。若确实要在其他设备访问，请先设置至少 12 位的 `REG_ADMIN_PASSWORD`，并配置 HTTPS。

## 文件说明

- `app.py`：本地网页服务、注册登录和功能接口。
- `ui.py`：网页界面。
- `zepp_client.py`：Zepp 登录、注册和微信绑定。
- `features.py`：设备查询、步数提交和支付宝授权。
- `requirements.txt`：运行依赖。

## 注意

项目使用的部分接口并非稳定公开 API，Zepp Life 更新后可能需要调整。请自行确认并遵守相关平台规则。不要公开分享账号密码、Token、`instance/` 数据库或加密密钥。
